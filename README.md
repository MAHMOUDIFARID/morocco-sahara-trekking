# Morocco Sahara Trekking

A modern trekking guide and booking website for expeditions across Morocco (High Atlas, M'Goun, and the Sahara Desert).

## Technologies

- Next.js 14
- TypeScript
- Tailwind CSS
- MDX

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
```
